# ЭкоКод

**Цифровая школа безопасности в лесу** — интерактивный статический веб-проект для школьников 10–15 лет.

## Что внутри

ЭкоКод превращает правила пожарной безопасности в короткую игровую практику. Пользователь проходит три последовательных сценария: поход с друзьями, рыбалка в тундре и семейный пикник. В каждом сценарии — пять ситуаций, выбор ответа, объяснение последствия и изменение показателя риска.

### Игровая механика

- три сценария с последовательным открытием;
- пять решений в каждом сценарии;
- XP за решения;
- показатель экориска;
- интерактивные точки игровой сцены;
- серия безопасных решений;
- достижения;
- профиль с именем или ником;
- локальное сохранение прогресса.

## Техническая структура

Проект намеренно сделан без React, Vite, npm и серверной части. Это готовый статический сайт:

```text
index.html
css/styles.css
js/app.js
.nojekyll
README.md
```

`index.html` подключает только локальные CSS и JavaScript. Внешних библиотек, аналитики и API для работы игры нет. Имя и игровой прогресс сохраняются только в `localStorage` браузера.

## Безопасность

- Content Security Policy без `unsafe-inline`;
- отсутствуют inline-обработчики событий;
- динамический пользовательский текст вставляется через DOM API;
- внешние ссылки на источники открываются с `noopener noreferrer`;
- нет форм авторизации, cookies и серверного хранения пользовательских данных.

## Публикация

Проект подготовлен для GitHub Pages как статический сайт. Сборка не требуется: Pages должна публиковать корень репозитория с ветки `main`.

## Содержательная база

Материалы по пожарной безопасности сформулированы на основе официальных материалов МЧС России и действующих федеральных правил противопожарного режима. Ссылки на источники находятся внутри сайта в разделе «Мой прогресс».

## Статус

Конкурсная статическая версия: интерфейс, игровые сценарии, сохранение прогресса и адаптивная верстка собраны в одном самостоятельном продукте.
